The requirements may change as the project develops

## Requirements

- When a user first visits the page, they will be redirected to the landing + login page
- Once a user has logged-in / registered, they will be redirected to their directory
- Here the user can create folders and upload files
- All CRUD operations will be supported in both folders and files. (Users cannot create files, only upload them)
- The user will be able to filter, sort and search files inside the directory


## Extra-credit requirements:
- Validate files (Do not allow files that are too heavy, limit uploading to certain file types only)
- Add a share folder functionality, when a user wants to share a file or folder, they will be able to generate a link
which will be valid for a certain duration of time, this link can be used by unauthenticated users to view file / folder contents
